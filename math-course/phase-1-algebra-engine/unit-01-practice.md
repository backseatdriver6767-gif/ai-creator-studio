## Set C — Calculus preview

These are difference quotients — the definition of the derivative, which you will
meet properly in Week 29. Every one is pure Unit 01 technique. Nothing here
requires calculus, and that is the point: when you reach Week 29, the calculus
will be the *only* new thing.

**C1.** For `f(x) = 1/x`, simplify `[f(x + h) - f(x)] / h`.

**C2.** For `f(x) = 1/(x + 1)`, simplify `[f(3 + h) - f(3)] / h`.

**C3.** Simplify `(1/(x + 2) - 1/2) / x`.

**C4.** For `f(x) = 2/x`, simplify `[f(x + h) - f(x)] / h`.

*Hint for all four: combine the numerator over a common denominator first. An `h`
(or `x`) will cancel. If nothing cancels, check your numerator algebra — these are
all built to collapse.*

## Timing benchmarks

Once you can do Set B correctly, do it again timed. Target for the full set of 20:

| Time | Verdict |
|---|---|
| Under 10 min, 20/20 | Automatic. Compress the unit and move on. |
| 10–18 min, 18+/20 | Solid. Proceed to Unit 02. |
| 18–25 min | Correct but effortful. Repeat the set in two days. |
| Over 25 min, or under 18/20 | Not yet free. Repeat daily until it is. |

Speed here is not vanity. It is the direct measure of whether this material has
stopped consuming working memory — which is the entire purpose of Phase 1.
